# Contributing

**Found a bug? [Open an issue.](../../issues/new/choose)** Say what you did, what you expected and what happened. The piece's logs and the version you are running help.

**We do not take pull requests on GitHub.** One opened here is closed with a link to this page. Writing code has become the easy part. Reading it, keeping the quality up and keeping the product one coherent thing is the hard part, and a pull request hands us the hard part.

**A patch by email is welcome.** If you have a fix, send it to [hi@openstudio.tech](mailto:hi@openstudio.tech) as a `git format-patch` file or a plain diff, with a line on what it fixes. We read every one. We may apply it, rewrite it or pass on it, and we will tell you which.

**An idea is best as an issue first.** Say what you want to do and why before writing any code.

**A security problem is not an issue.** See [SECURITY.md](SECURITY.md).

Anything you send is offered under the same [licence](LICENSE.md) as the rest.

This may change as the project grows up. Thank you for understanding.
